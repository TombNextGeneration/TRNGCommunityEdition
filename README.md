# TRNG - Community Edition

TRNG - Community Edition (TRNG-CE) is an open source and community driven Tomb Raider engine based on Tomb Raider Next Generation (TRNG) by Paolone.

Currently a dynamic library, TRNG-CE replaces and improves TRNG from the bottom up, step by step, to become in the end a standalone program encompassing also FLEP and TRNG plugins.

## Getting Started

Simply download the [latest TRNG-CE release](https://github.com/TombNextGeneration/TRNGCommunityEdition/releases/latest) and extract the contents in your existing game folder (normally named Engine).

Visit us on [TRNG - Community Edition Discord server](https://discord.gg/JJgQUYKBB6) to follow development, get involved, and ask questions.
