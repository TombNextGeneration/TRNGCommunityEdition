# How to contribute

To make changes to the code, you will need an account at [GitHub](https://github.com) and make use of [Git](https://gitforwindows.org) and [Visual Studio](https://visualstudio.microsoft.com/downloads).

## Visual Studio installation

In the Visual Studio Installer, choose the Desktop development with C++ workload.
Add the latest version of the MSVC v143 - VS 2022 C++ x64/x86 build tools and the vcpkg package manager from the Individual components tab.

After the the installation is complete, open Visual Studio, select Tools > Command Line > Developer Command Prompt and run this command:

```
vcpkg integrate install
```

## Issues

Use the [issues page](https://github.com/TombNextGeneration/TRNGCommunityEdition/issues) for reporting bugs or requesting new features.
Alternatively, you can do so in our [server](https://discord.gg/JJgQUYKBB6), and a team member will submit an issue on your behalf.

Describe the bug/feature as precisely as you can and include images and videos if needed.

## Pull requests

You can submit any pull request to this project.
Read the [GitHub flow](https://docs.github.com/en/get-started/using-github/github-flow) to learn how to collaborate and browse the [style guide](STYLE.md) to know our code conventions.
